# Coffee Website

A simple, responsive coffee shop website built with HTML and CSS.

## Features

- Home page hero section
- About, menu, testimonials, gallery, and contact sections
- Responsive navigation for smaller screens
- Contact form layout
- Local coffee and drink photos

## Run Locally

Open `index.html` in a web browser. No installation or build step is required.

## Project Files

- `index.html` — page content and navigation
- `style.css` — layout, colors, and responsive styles
- `coffee.jpg` and drink image files — photos used on the site
